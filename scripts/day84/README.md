# Day84 实时面试题集（2）+ 综合自测口述自查清单

> 用法：对着题目口述，卡住回到笔记 Day84 补；薄弱项每天过一遍。

## 架构题 10 题
1. **实时 vs 离线？** 时效/计算/存储/口径 四角度
2. **四层？** ODS 原始 / DWD 清洗口径 / DWS 汇总 / ADS 报表；Kafka 存 Flink SQL 算
3. **Lambda vs Kappa？** 双链路维护贵口径不一致 / 单链路重算贵
4. **对账？** 口径统一前提；窗口近似/迟到/丢失/口径差异
5. **维表？** 缓存 / 异步IO / 广播流；兜底 + 侧输出 + 回补
6. **Exactly-Once？** source offset + checkpoint 状态 + sink 两阶段提交
7. **背压？** HIGH 边下游；攒批异步/加盐/提并行度/换RocksDB
8. **报表延迟？** 窗口粒度 + 落库策略；只写聚合
9. **Watermark？** 水位线；触发≥窗口结束；清窗≥结束+allowedLateness
10. **项目四段式？** 背景/架构/关键设计/成果 + 生产差距

## 概念题 5 题
C1. checkpoint 自动 vs savepoint 手动
C2. 小状态 HashMap / 大状态 RocksDB
C3. 滑动可重叠
C4. SQL 简单统计报表 join；DataStream 复杂状态/自定义水印触发器
C5. 3 分区同组最多 3 消费者（⚠️易错）

## 场景题 2 题
S1. 延迟+lag 排查：背压→lag 分布→生产/消费速率→Sink→倾斜→资源（6步）
S2. 热点 key：加盐两阶段聚合 / 热点单独通道 / 小表广播（提并行度无效）
