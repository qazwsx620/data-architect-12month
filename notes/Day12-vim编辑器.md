## 1. vim 三种模式（面试必考）

| 模式 | 作用 | 进入/退出 |
|------|------|-----------|
| 普通模式 | 默认，执行命令（删除/复制/移动） | 打开即进入；`Esc` 从其他模式返回 |
| 插入模式 | 编辑文本 | 普通模式按 `i`(光标前)/`a`(光标后)/`o`(下方新行) |
| 末行模式 | 保存/退出/替换/分屏/行号 | 普通模式按 `:` |

> ⚠️【易混淆坑】**插入模式下按 `:wq` 只是输入文本字符，不会执行命令**；必须先 `Esc` 回普通模式，再按 `:`。

## 2. 保存与退出（必背）

```bash
:wq        # 保存并退出
:q         # 退出（未修改时）
:q!        # 强制退出不保存（丢弃所有修改）
:w         # 只保存
ZZ         # 普通模式下保存并退出（等效 :wq）
```

## 3. 普通模式常用操作

**移动**
```bash
h j k l     # 左 下 上 右
0           # 行首（含空格）
^           # 本行第一个非空白字符
$           # 行尾
gg          # 文件第一行
G           # 文件最后一行
10G         # 第10行
w / b / e   # 下一个/上一个/当前单词边界
```

**删除/复制/粘贴**
```bash
x        # 删光标字符
dd       # 删除（剪切）当前行；5dd 删5行
dw       # 删一个单词
cw       # 删单词并进入插入模式（修改单词）
yy       # 复制当前行；5yy 复制5行
p / P    # 粘贴到下方/上方
u        # 撤销；Ctrl+r 重做
v / V    # 字符可视模式 / 行可视模式（选中后 y复制 d删除）
```

> ✅【面试高频】`dd` 本质是**剪切**，内容存入寄存器，`p` 可粘贴恢复；不是单纯丢弃。
> 区分：`dw` 删除后留在普通模式；`cw` 删除后自动进插入模式。

## 4. 查找与替换（末行模式）

```bash
/关键词      # 向下查找，n下一个 N上一个
?关键词      # 向上查找
:set nu      # 显示行号；:set nonu 取消
:set ic      # 搜索忽略大小写；:set noic 恢复

:s/old/new/        # 替换当前行第一个
:s/old/new/g       # 替换当前行全部
:%s/old/new/g      # 全文件替换（% 所有行）
:%s/old/new/gc     # 全文件替换，逐个询问确认（y/n/a/q）
```

**路径替换免转义（面试技巧）**
```bash
:%s#/etc/nginx#/etc/httpd#g    # 用 # 作分隔符，/ 不用转义
```
> ⚠️【易混淆坑】不带 `g` 只替换每行第一个匹配；`c` = confirm 逐个确认。

## 5. 分屏操作

```bash
:sp      # 水平分屏（上下）
:vsp     # 垂直分屏（左右）
Ctrl+w w # 窗口间切换
:q       # 关闭当前分屏
:qall    # 全部退出
:wqall   # 全部保存退出
```

## 6. .swp 交换文件（异常退出）

- 产生：vim 非正常关闭（断电、ssh 强断、进程被杀）时生成 `.xxx.swp`
- 处理：重新打开时提示，`R` 恢复未保存内容，`D` 删除交换文件
> ⚠️ 不删除 swp，每次打开文件都会弹警告。

## 7. vim 配置 ~/.vimrc

```bash
echo "set nu" >> ~/.vimrc
echo "set tabstop=4" >> ~/.vimrc
echo "syntax on" >> ~/.vimrc
```
常用：`set nu` 行号、`set tabstop=4` tab 宽度、`syntax on` 语法高亮。

## 今日面试考点清单
1. vim 三种模式及切换？→ 普通/插入/末行；Esc 回普通，i/a/o 进插入，: 进末行
2. 插入模式下 :wq 能保存吗？→ 不能，只是文本字符，先 Esc
3. dd 误删怎么恢复？→ u 撤销 或 p 粘贴寄存器
4. dw 与 cw 区别？→ 删除留普通模式 vs 删除进插入模式
5. 0 与 ^ 区别？→ 行首含空格 vs 第一个非空白字符
6. :%s/error/ERROR/g 作用？→ 全文替换所有 error 为 ERROR
7. 替换路径为什么用 # 分隔符？→ 免 / 转义
8. .swp 文件怎么来的？R/D 分别做什么？→ 异常退出生成；R 恢复，D 删除
9. :sp 与 :vsp 区别？→ 水平分屏 vs 垂直分屏

## 踩坑记录（面试素材）
- 插入模式输 :wq 保存失败 → 先 Esc 再 :
- dd 以为内容被丢弃 → 剪切进寄存器，p 可粘贴
- 替换不带 g 只改每行第一个 → 全文替换要 :%s/old/new/g
- 路径替换疯狂加 \ 转义 → 换 # 分隔符
- swp 文件不删，每次打开弹警告 → R 恢复 / D 删除
