## 2. 项目全链路（7 环节）

```
抽取(ODS) → 清洗(DWD) → 汇总(DWS) → 报表(ADS)
    → 质量校验(每层) → 导出(CSV/HTML) → 调度(crontab 02:00)
```

## 3. 面试推荐讲的 3 个坑（话术已备）
1. **连错库 Unknown column** → 配置独立+核对连接对象
2. **脏数据 -50 逐层传染** → 每层校验+血缘反查源头
3. **幂等重跑** → 先删后插/TRUNCATE，重跑安全
