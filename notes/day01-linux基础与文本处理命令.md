## 一、今日学习内容

### 1. 文件与目录操作
| 命令 | 作用 | 常用参数 |
| --- | --- | --- |
| `pwd` | 显示当前目录 | - |
| `ls` | 列出目录内容 | `-l` 详细、`-a` 含隐藏、`-h` 人类可读 |
| `cd` | 切换目录 | `cd ..` 上级、`cd ~` 家目录 |
| `mkdir` | 创建目录 | `-p` 递归创建 |

| `mv` | 移动/重命名 | - |

| `less` | 分页查看 | 空格翻页、q 退出 |
| `grep` | 文本过滤 | 见下 |

### 2. 权限管理
- 权限位：`rwx`（读 4 / 写 2 / 执行 1），三组：属主、属组、其他
- `chmod 755 file`：数字法设置权限
- `chown user:group file`：修改属主属组

### 3. 输出重定向
- `>` 覆盖写入：`echo "hello" > test.log`
- `>>` 追加写入：`echo "hello" >> test.log`
- 面试点：`>` 会清空原文件，`>>` 保留原内容追加

### 4. 管道与文本处理（今日重点）
- 管道符 `|`：前一个命令的输出作为后一个命令的输入，一屏命令组合解决统计/过滤/提取问题

| 命令 | 作用 | 关键参数 |
| --- | --- | --- |
| `wc` | 统计 | `-l` 行数、`-w` 单词、`-c` 字符 |
| `sort` | 排序 | `-r` 倒序 |
| `uniq` | 去重 | `-c` 统计次数、`-d` 只显示重复行 |
| `cut` | 按分隔符取列 | `-d ":"` 指定分隔符、`-f 2` 取第2列 |
| `awk` | 文本处理（入门） | `'{print $2}'` 取第2字段、`-F ":"` 指定分隔符 |
| `grep` | 按内容过滤 | `grep "error" file` |

## 二、今日实操记录

练习日志文件 `test.log` 样例：
```
2026-09-16 warn:timeout
2026-09-16 info:server start
2026-09-16 error:connect failed
2026-09-16 debug:load data success
2026-09-16 error:connect failed
```

综合命令：提取日志级别并统计出现次数
```bash
cat test.log | awk '{print $2}' | cut -d ":" -f 1 | sort | uniq -c
# 输出：
#       1 debug
#       2 error
#       1 info
#       1 warn
```

统计日志级别种类数（去重后计数）：
```bash
cat test.log | awk '{print $2}' | cut -d ":" -f 1 | sort | uniq | wc -l
# 输出：4
```

筛选 error 日志数量：
```bash
grep "error" test.log | wc -l
# 输出：2
```

## 三、面试考点 / 错题本（必复习）

1. **uniq 的坑**：只去除「相邻」的重复行；重复行不相邻时去重无效。标准用法：`sort | uniq`
2. **cut 的坑**：只适合分隔符统一的文本（冒号、逗号等固定单字符）；多个空格/分隔不固定时不要用 cut，改用 awk
3. **awk 默认分隔符**：任意空白（空格、Tab，多个连续空格视为一个分隔符）；`-F ":"` 可指定自定义分隔符
4. **综合管道思路**：过滤（grep）→ 字段提取（awk/cut）→ 排序（sort）→ 去重统计（uniq -c）→ 计数（wc -l）
