# 模块一：Linux 基础与运维（Day01-10）

## Day01 Linux 基础与文本处理命令 ✅ 已入库
- 学习：ls/cd/mkdir/rm/cp/mv、cat/tail/head/less、grep、管道 `|`
- 实操：多级目录操作；grep 过滤日志 ERROR 关键词
- 面试：文件权限数字含义；rm 与句柄释放

## Day02 Shell 脚本基础 ✅ 已入库
- 学习：变量、单双引号、位置参数 $1/$2、命令替换、if 判断、for 循环
- 实操：日志统计脚本 count_log.sh、level_stat.sh
- 面试：单引号与双引号区别；for 循环写法

## Day03 文本三剑客 sed 与 awk ✅ 已入库
- 学习：awk 列处理（$0/$1、BEGIN/END、统计）、sed 行替换（s/old/new/g、-i）
- 实操：awk 日志分级统计、sed 批量替换/删除
- 面试：awk 与 sed 适用场景；sed -i 备份

## Day04 进程管理与定时任务 ✅ 已入库
- 学习：ps/pgrep/top、kill 信号（SIGTERM/SIGKILL）、Ctrl+C/Z、fg/bg、nohup &、crontab
- 实操：后台循环脚本 loop_demo.sh、crontab 定时采集
- 面试：kill 与 kill -9 顺序；2>&1；nohup 作用；crontab 绝对路径

## Day05 文件系统与权限管理 ✅ 已入库
- 学习：inode、硬链接/软链接、rwx 权限（文件 vs 目录）、chmod/chown、umask、SUID/SGID/Sticky、mount/umount
- 实操：软硬链接对比 link_demo.sh、特殊权限实验、loop 镜像挂载
- 面试：软硬链接区别；目录 w/x 权限坑；umask 计算；target busy

## Day06 系统日志与故障排查 ✅ 已入库
- 学习：syslog（facility/priority）、journalctl、dmesg、logrotate、磁盘爆满排查
- 实操：日志查看、logrotate 配置解析、磁盘排查 disk_check.sh
- 面试：auth.log 定位 SSH 故障；dmesg vs journalctl -k；rm 大日志不释放空间

## Day07 网络基础 ✅ 已入库
- 学习：ip addr/route、DNS（netplan）、ss 端口、TCP 三次握手四次挥手、tcpdump、ufw、mtr
- 实操：网络排查 net_check.sh、抓包观察握手
- 面试：网络排查顺序；0.0.0.0 vs 127.0.0.1；TIME_WAIT 2MSL；ping 通但端口不通

## Day08 性能调优 ✅ 已入库
- 学习：top（load/CPU）、free（available）、vmstat（si/so/wa）、iostat（await/svctm）
- 实操：性能检查 perf_check.sh
- 面试：load 与核数；available 判断内存；wa 高；await>>svctm

## Day09 Linux 综合实战（待执行）
- 学习：find/xargs、tar/gzip 压缩归档、综合巡检脚本
- 实操：写巡检脚本：磁盘使用率/内存/CPU/端口占用输出到日志（自己写 shell）
- 面试：find 常用参数；tar 打包压缩组合
- 大厂专项：收到告警「CPU 高 + 磁盘持续上涨」，完整排查流程写成文档

## Day10 故障模拟实战（待执行）
- 故障模拟：死循环拉高 CPU 用 top 定位终止；大量小文件占满 inode；端口冲突复现；权限故障复现
- 整理全部踩坑记录为面试项目素材
- 面试：全部 Linux 面试题完整口述一遍，卡住的标记薄弱项

# 模块二：MySQL 深度（Day11-22）

## Day11 MySQL 安装与基础 CRUD
- 学习：安装 MySQL8.0、库表创建、INSERT/SELECT/UPDATE/DELETE
- 实操：建用户表练习增删改查
- 面试：MySQL 逻辑架构分层

## Day12 数据类型与约束
- 学习：整数/字符串/日期类型、主键/外键/唯一/非空约束
- 实操：设计订单表，验证约束
- 面试：int 与 bigint 选择；varchar 长度策略

## Day13 索引原理 B+ 树
- 学习：B+ 树原理、聚簇索引、非聚簇索引、回表
- 实操：自建表验证主键与数据存储关系
- 面试：B+ 树对比 B 树；回表是什么、如何避免

## Day14 explain 执行计划
- 学习：id、select_type、type、key、rows、Extra
- 实操：构造 SQL 执行 explain，逐列解读
- 面试：type 从优到劣顺序；type=ALL 如何优化

## Day15 联合索引与覆盖索引
- 学习：联合索引最左前缀原则、覆盖索引
- 实操：创建联合索引验证最左前缀命中情况
- 面试：联合索引 (a,b,c) 哪些 where 能命中

## Day16 索引失效与设计原则
- 学习：函数操作、隐式转换、or、like 前导 % 等失效场景；建索引原则与弊端
- 实操：逐个复现失效场景并改写修复
- 面试：列举 5 种索引失效；为什么索引不是越多越好

## Day17 事务 ACID 与 redo/undo
- 学习：ACID 四大特性、redo log、undo log
- 实操：手动 commit/rollback 观察数据变化
- 面试：ACID 含义；redo log 如何保证崩溃安全

## Day18 隔离级别
- 学习：四种隔离级别、脏读/不可重复读/幻读
- 实操：修改隔离级别复现三种异常
- 面试：InnoDB 默认隔离级别；各级别解决什么问题

## Day19 MVCC
- 学习：Read View、undo log 版本链
- 实操：事务实验理解多版本
- 面试：MVCC 实现原理；能否解决幻读

## Day20 InnoDB 锁机制
- 学习：行锁、表锁、间隙锁、临键锁
- 实操：双会话制造锁等待
- 面试：间隙锁触发时机；锁冲突排查

## Day21 主从复制与分库分表
- 学习：主从复制原理、binlog、水平/垂直拆分
- 实操：搭建简易主从（可选）
- 面试：主从延迟原因与排查

## Day22 慢 SQL 优化实战 + 月末自测
- 综合实操：构造慢 SQL 全部优化，输出优化报告（附 explain）
- 月末核验：Linux 实操代码入库、MySQL 实验文档、全部面试题可口述、故障案例记录
