# 阶段01 · 第1月 每日打卡清单（Linux + MySQL 深度）

> 总纲核对：阶段01 为第 1-2 月地基夯实；本月为第 1 月，每周 6 天学习（3-5h/天），周日复盘休息。
> 方案B：每日叠加「大厂场景专项 + 故障模拟演练」。
> 规则：实操只给提示不给完整代码；产出物统一提交 Git 仓库。

## 每日固定结构（全程不变）
1. 0.5h → 复习上周/昨日核心知识点（口述自查）
2. 2.5~4h → 新知识学习 + 动手实操（实操占比 ≥60%）
3. 0.5h → 整理当日面试考点，打磨口述答案
4. 附加：大厂场景思考题 + 故障模拟演练

## 前置准备
1. 虚拟机：CentOS7 / Ubuntu22.04，分配 2核4G
2. 软件：MySQL8.0、vim、git
3. Git 仓库：本项目（`data-architect-12month`），目录：`linux/`、`mysql/`、`notes/`、`interview/`
4. 规则：遇到报错先看日志自行排查，卡住再贴报错要排查方向

# 第1周：Linux 基础命令、文件权限、进程、磁盘IO
> 周目标：熟练 Linux 基础运维排查；学会日志查看；能独立排查 CPU、磁盘基础问题。
> 大厂专项：重点训练「线上服务器排查思路」。

## 周一
- 复习（0.5h）：本周开篇，浏览本周目录
- 学习：基础命令 `ls、cd、mkdir、rm、cp、mv、cat、less、grep`；文件权限 rwx、chmod、chown
- 实操提示：
  1. 新建多级目录，练习修改文件/文件夹权限；创建只读、仅可执行文件，验证权限限制效果
  2. 用 grep 过滤日志文件，筛选 ERROR 关键词
- 面试整理：Linux 文件权限数字代表什么？chmod 755、644 含义？
- 大厂专项：
  - 场景题：线上业务日志文件突然无法读取，排查步骤是什么？（写下思路）
  - 故障模拟：手动修改文件权限制造权限不足报错，记录报错与解决步骤

## 周二
- 复习（0.5h）：rwx 权限、chmod/chown
- 学习：进程命令 `ps、top、pstree、kill`；理解 PID 与进程状态
- 实操提示：
  1. top 观察 CPU、内存占用，找到高 CPU 进程记录 PID
  2. 后台运行程序，练习 kill 正常终止与 kill -9 强制杀死，对比差异
- 面试整理：top 字段含义；kill 与 kill -9 区别，什么时候不能直接 kill -9
- 大厂专项：
  - 场景题：线上机器 CPU 100%，完整排查流程？（写出步骤）
  - 故障模拟：写死循环脚本拉高 CPU，用 top 定位进程并终止

## 周三
- 复习（0.5h）：进程命令、top 字段
- 学习：磁盘相关 `df、du、iostat`；磁盘分区、inode 基础概念
- 实操提示：
  1. df 查看磁盘整体使用率；du 定位大文件目录
  2. 新建大量小文件，观察 inode 占用情况
- 面试整理：df 显示满但 du 找不到大文件，可能是什么原因？
- 大厂专项：
  - 场景题：服务器磁盘打满业务报错，如何紧急处理、后续根治？
  - 故障模拟：创建大量临时小文件占满磁盘，模拟故障并清理恢复

## 周四
- 复习（0.5h）：磁盘命令、inode 知识点
- 学习：网络命令 `netstat、ss、ping`；端口查看与占用定位
- 实操提示：
  1. ss 查看端口监听；找到占用特定端口的进程
  2. 模拟端口冲突，观察报错
- 面试整理：ss 与 netstat 对比；端口被占用怎么排查？
- 大厂专项：
  - 场景题：服务启动提示端口已占用，线上紧急排查方案
  - 故障模拟：两个程序占用同一端口，复现端口冲突

## 周五
- 复习（0.5h）：本周全部命令回顾
- 学习：管道 `|`；输出重定向 `>`、`>>`；标准输出/错误输出
- 实操提示：
  1. 结合 grep，将命令输出保存到日志文件
  2. 区分覆盖 `>` 与追加 `>>`
- 面试整理：`>` 与 `>>` 区别；`2>&1` 含义？
- 大厂专项：
  - 场景题：后台脚本执行，如何把正常日志与错误日志分开保存？
  - 故障模拟：把错误流单独输出到 error.log，验证效果

## 周六
- 复习（0.5h）：本周全部知识点口述自查
- 综合实操：写简易巡检脚本：输出磁盘使用率、内存、CPU、端口占用，输出到巡检日志文件（只构思逻辑，自己写 shell）
- 面试整理：本周全部面试题完整口述一遍
- 大厂专项：
  - 综合场景题：收到告警「CPU 高 + 磁盘持续上涨」，完整排查流程写成文档

## 周日 复盘休息
- 整理本周实操产出，全部提交 Git（写清 commit 说明）
- 默写核心知识点，口述全部面试题；卡住的标记为薄弱项
- 复盘故障模拟踩坑记录，整理成面试项目素材
- 预习第2周：awk、sed 基础

# 第3周：MySQL 索引原理、explain 执行计划、索引失效
> 周目标：看懂执行计划、识别索引失效、独立优化 SQL；大厂高频 SQL 优化面试。

## 周一
- 复习（0.5h）：shell 脚本回顾
- 学习：B+ 树原理；聚簇索引、非聚簇索引；回表
- 实操提示：自建用户表（主键索引），理解主键与数据存储关系
- 面试整理：B+ 树对比 B 树；聚簇与非聚簇索引；回表是什么
- 大厂专项：场景题：什么情况会发生回表？如何避免？

## 周二
- 复习（0.5h）：B+ 树、回表
- 学习：explain 字段：id、select_type、type、key、rows、Extra
- 实操提示：构造 SQL 执行 explain，逐列解读含义
- 面试整理：explain 中 type 从优到劣顺序；Extra 常见字段含义
- 大厂专项：场景题：explain 显示 type=ALL，代表什么，如何优化？

## 周三
- 复习（0.5h）：explain 字段
- 学习：覆盖索引、联合索引最左前缀原则
- 实操提示：创建联合索引，写多条 SQL 验证最左前缀，观察命中情况
- 面试整理：联合索引最左前缀原理；覆盖索引的好处
- 大厂专项：场景题：联合索引 (a,b,c)，哪些 where 条件能命中索引？

## 周四
- 复习（0.5h）：联合索引
- 学习：索引失效场景：函数操作、隐式转换、or、like 前导 %
- 实操提示：逐个复现失效场景，看 explain 结果，改写 SQL 修复
- 面试整理：列举 5 种索引失效场景
- 大厂专项：故障模拟：业务 SQL 突然不走索引，定位失效原因并优化

## 周五
- 复习（0.5h）：索引失效场景
- 学习：索引设计原则；什么时候不适合建索引
- 实操提示：针对订单表评估哪些字段适合建索引，写出索引方案
- 面试整理：索引不是越多越好，为什么？索引的弊端？
- 大厂专项：场景题：大表频繁更新，索引过多带来什么问题？

## 周六
- 复习（0.5h）：本周全部索引知识点口述
- 综合实操：设计测试表，构造多条慢 SQL，explain 分析并全部优化，输出优化报告
- 面试整理：本周面试题完整口述
- 大厂专项：综合场景题：线上订单查询 SQL 越来越慢，完整排查 + 优化方案

# 第4周：MySQL 事务 ACID、隔离级别、MVCC、锁、主从复制、分库分表
> 周目标：吃透事务底层；大厂数据库面试重中之重。

## 周二

- 学习：四种隔离级别；脏读、不可重复读、幻读

- 面试整理：四种隔离级别分别解决什么问题；InnoDB 默认隔离级别

## 周三
- 复习（0.5h）：隔离级别
- 学习：MVCC 原理：Read View、undo log 版本链
- 实操提示：结合事务实验理解多版本数据
- 面试整理：MVCC 实现原理；Read View 作用
- 大厂专项：场景题：MVCC 能不能解决幻读？

## 周四
- 复习（0.5h）：MVCC
- 学习：InnoDB 锁：行锁、表锁、间隙锁、临键锁
- 实操提示：开启两个会话，制造锁等待现象
- 面试整理：间隙锁什么时候触发，解决什么问题
